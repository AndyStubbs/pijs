Sound Lab

Shape a synthesized sound and compare it with recorded Pi.js 2.2 renders. Serve the repository with npm run server after npm run build, then open this page from http://localhost:8080/test/demos/sound_lab_01.html.

Master Volume

0.75

Keep the master volume at 0.75 for level-matched A/B listening: the recorded references include the 2.2 default master volume.

The limiter passes levels below its threshold unchanged. Turn it off to hear the raw mix; set it before playing.
