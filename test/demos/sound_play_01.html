Sound Play

Listening demo for play() on the lookahead scheduler: PLAY envelopes, articulation, pan, noise percussion, simultaneous tracks, and long songs. Use it to tune the default envelope (MA 15, MD 20, MH 65, MR 20) by ear. Serve the repository over HTTP (npm run server) so the 2.2 reference can load.

Envelope and articulation

A comma starts a track at the previous track's last command, so "C D E, G" plays G with E. The long song has several hundred notes; hiding the tab widens the lookahead window, and it should keep playing without gaps.
